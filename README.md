# Tartil_Hasanat_unity (تريل حسنات) 🌙✨

An interactive 2D top-down Islamic game built with **Unity** and **C#**, designed to encourage good deeds and positive values through engaging gameplay mechanics.

## 🎥 Gameplay Demo
[Watch the Demo Video on YouTube](https://youtu.be/S4DDQ4tpVco)

## 🚀 Key Features & Technical Implementation
* **Mission & Proximity Interaction (`HasanatMission.cs`):** Implemented 2D trigger colliders and interactive NPC tasks where players assist characters to earn good deeds.
* **Real-Time Score System (`HasanatCounter.cs`):** Dynamic UI counter tracking player progress and completed good deeds.
* **Audio-Visual Feedback:** Integrated synchronized voiceovers, sound effects, and 2D particle celebrations upon task completion.

## 🛠️ Technologies Used
* **Engine:** Unity (2D)
* **Language:** C#
